# Qwen3-VL-8B 压力测试报告

> 测试对象：AI 服务器（192.168.1.5）vLLM 服务 Qwen3-VL-8B-FP8（端口 8002）
> 测试时间：2026-10-09
> 测试目的：评估 8B 在知识库场景下的并发能力，判断**是否 OOM**、**free 5G 显存够不够用**，得出可用并发上限

---

## 1. 测试环境

| 项 | 值 |
|---|---|
| 模型 | Qwen3-VL-8B-Instruct-FP8（官方 FP8） |
| 推理框架 | vLLM 0.12.0（`/opt/vllm-venv-new`） |
| 服务配置 | gpu-memory-utilization 0.57 / max-model-len 4096 / enforce-eager |
| 测试地址 | `http://127.0.0.1:8002/v1/chat/completions` |
| 显存基线 | 总 32607 MiB，used 26962，**free 5149**（embedding 10.7G + rerank 2.4G + VL 13.5G） |
| 并发工具 | ThreadPoolExecutor（服务器本地并发请求） |

---

## 2. 测试方法

分 3 个场景逐步加压，每批全部请求完成后记录成功率、延迟 P50/P95、GPU 显存与利用率：

| 场景 | 并发梯度 | 说明 |
|---|---|---|
| 纯文本 | 1 / 2 / 4 / 8 / 16 | max_tokens=128，模拟知识库短问答 |
| 多模态(图片OCR) | 1 / 2 / 4 / 8 | 传 base64 图片让模型读图，模拟看图/文档识别 |
| 长输出 | 4 / 8 | max_tokens=512，模拟详细长回答 |

## 4. 核心结论

### 4.1 是否 OOM？—— **不会 OOM**

- **显存全程零波动**：所有场景、所有并发梯度下，显存 `used 26962 / free 5149 MiB` **固定不变**。
- vLLM 在启动时已按 `gpu-memory-utilization 0.57` 预分配 KV cache（可用 1.09G），并发请求只消耗**已预留的 KV cache**，不产生新的显存分配，因此不会触发 OOM。
- 压测最大并发（文本 16 + 多模态 8）全部成功，0 失败，服务存活——**没有 OOM 迹象**。

### 4.2 free 5G 够不够？—— **够，且是安全余量**

- 压测全程 free 稳定在 **5.15G**，未减少。这 5G 是 vLLM **未预分配**的系统级余量，留给 embedding/rerank 峰值和系统抖动。
- 结论：free 5G 在 8B 的并发场景下**完全够用**，且作为安全缓冲是合理的（不必再压榨）。

### 4.3 并发能力与延迟

| 能力维度 | 结论 |
|---|---|
| 短输出并发 | 文本 16 并发、多模态 8 并发全部成功，P50 稳定 ~0.5-0.6s |
| 长输出(512 token) | 8 并发 P50 ~10s（吞吐受 KV cache + 计算限制） |
| 并发瓶颈 | 非显存，而是 KV cache（1.09G）与 GPU 计算吞吐 |

**可用并发建议**：
- **交互式问答**（短输出）：并发 8-16 无压力，P50 <1s，体验流畅。
- **多模态看图/OCR**：并发 8 内稳定，推荐 ≤8。
- **后台批量文档富化/长输出**：建议并发 ≤4，长回答吞吐约每秒 50 token/请求。

## 5. 与 7B 对比（参考）

| 维度 | 7B-AWQ | 8B-FP8 |
|---|---|---|
| 显存占用 | ~11.7G | ~13.5G |
| free 余量 | ~7.2G | ~5.1G（仍充足） |
| OCR 能力 | 基线 | 明显提升（OCRBench 864→896） |
| 文本/文档能力 | 基线 | 明显提升 |

8B 虽多占 ~1.8G 显存，但 free 仍 5.1G，且能力全面提升，**替换收益大于显存成本**。

---

## 6. 建议

1. **保持现配置**（0.57 / 4096 / enforce-eager）：显存安全、free 充足，无需调整。
2. **WeKnora 并发限制**：若知识库有后台文档富化任务，建议在模型配置里把"后台并发上限"设为 **4**，避免长输出长时间占用 KV cache 挤占交互请求。
3. **监控**：可加个简单监控（`nvidia-smi` 定时记录），关注 free 是否跌破 2G（当前远高于此）。
4. **回滚保障**：7B 模型与服务保留，随时可回滚。
